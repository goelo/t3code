# T3 Code 增强版采用独立 macOS 应用

增强版从已安装中文版的源码提交构建，由 `goelo/t3code-enhancer` 交付。增强版有独立的应用标识、Electron 配置和本地 T3 数据目录。两个客户端可以连接同一个 T3 环境查看已有历史，数据库由该环境的服务进程独占。

增强版默认从 43773 查找自己的本机服务端口，原 Mac 环境继续使用 3773。已保存的连接按环境标识识别原 Mac 环境。

需要在中文版退出后继续访问原 Mac 环境时，由 macOS 用户级后台服务接管原环境的数据目录和 3773 端口。服务使用增强版随附的 T3 程序。增强版和手机沿用原环境的连接，手机可通过恢复后的 T3 Connect 隧道访问。
